A cookbook starts from a question someone actually asks and walks to the answer, with every query run against the [demo](/start/quickstart/). Pick one.

| Cookbook | Question | You use |
|---|---|---|
| [Dairy traceability](/cookbooks/dairy-traceability/) | A quality test failed: which lot, which batches, which retailers? | SPARQL, validation |
| [A data catalog](/cookbooks/data-catalog/) | What do we have, who owns it, and what depends on it? | assets, search, lineage |
| [Rules and compliance](/cookbooks/compliance-rules/) | Which records break which rule, and why? | constraints, expectations, waivers |
| [Agent memory](/cookbooks/agent-memory/) | How does an assistant remember what it learned, on the record? | MCP memory tools, grants |

Each ends with what to try next. They all assume the demo's dairy cooperative unless they say otherwise.
