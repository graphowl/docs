Pick how you want to run it.

<Tabs>
<TabItem label="Use the demo">

The demo is a live server loaded with a **synthetic dairy cooperative**: farms, milk lots, quality tests, production batches and retail sales. Access is by **passcode**, from a booked time slot.

<Steps>

1. **Book a time.** Go to [demo.graphowl.app](https://demo.graphowl.app/__access/book) and choose **20 minutes of hands-on access** (the demo is yours alone for that slot). Pick a day, then a time from the list, and enter your name and email. You are shown a passcode like `OWL-XXXX-XXXX` straight away: copy it, it is shown once. Want a guided tour instead? Choose the **30-minute walkthrough call** with the author: times are shown as buttons you pick from (Tuesdays and Saturdays), and no passcode is needed for that.

2. **Open the console.** When your slot starts, go to [demo.graphowl.app](https://demo.graphowl.app), enter the passcode, and you are in the console with the Northfield Dairy Cooperative workspace.

3. **Ask your first question in the console.** Open **Query** in the left menu, paste this SPARQL and run it. It counts the instances of each class. Imported facts live in named graphs, so the pattern sits inside `GRAPH ?g { ... }`.

   ```sparql
   SELECT ?class (COUNT(?s) AS ?n)
   WHERE { GRAPH ?g { ?s a ?class } }
   GROUP BY ?class ORDER BY DESC(?n)
   ```

   The answer lists the classes with the most instances: cold-chain readings and quality tests at 46 each, then milk lots at 40, then batch lots at 25. The same screen takes graph patterns (openCypher), such as `MATCH (n:MilkLot) RETURN count(n) AS lots`.

4. **Or call the API.** The passcode is your API key: send it as a bearer token.

   <Tabs>
   <TabItem label="curl">

   ```bash
   export PASSCODE=OWL-XXXX-XXXX

   curl -H "Authorization: Bearer $PASSCODE" https://demo.graphowl.app/health
   # {"status":"alive","version":"0.1.0"}

   curl -X POST https://demo.graphowl.app/sparql \
     -H "Authorization: Bearer $PASSCODE" -H "Content-Type: application/json" \
     -d '{"query": "SELECT ?class (COUNT(?s) AS ?n) WHERE { GRAPH ?g { ?s a ?class } } GROUP BY ?class ORDER BY DESC(?n) LIMIT 5"}'
   ```

   </TabItem>
   <TabItem label="Python">

   Install the client from its repository, then use the passcode as the key:

   ```bash
   pip install "git+https://github.com/graphowl/python-client"
   ```

   ```python
   from graphowl import GraphOWL

   owl = GraphOWL(url="https://demo.graphowl.app", api_key="OWL-XXXX-XXXX", workspace="dairy-coop")
   rows = owl.query.sparql("""
     SELECT ?class (COUNT(?s) AS ?n)
     WHERE { GRAPH ?g { ?s a ?class } }
     GROUP BY ?class ORDER BY DESC(?n) LIMIT 5""")
   print(rows)
   ```

   </TabItem>
   <TabItem label="TypeScript">

   ```ts
   const res = await fetch("https://demo.graphowl.app/sparql", {
     method: "POST",
     headers: { Authorization: "Bearer OWL-XXXX-XXXX", "Content-Type": "application/json" },
     body: JSON.stringify({
       query: "SELECT ?class (COUNT(?s) AS ?n) WHERE { GRAPH ?g { ?s a ?class } } GROUP BY ?class ORDER BY DESC(?n) LIMIT 5",
     }),
   });
   const { rows } = await res.json();
   ```

   </TabItem>
   </Tabs>

5. **Ask it as a graph pattern.**

   ```bash
   curl -X POST https://demo.graphowl.app/cypher \
     -H "Authorization: Bearer $PASSCODE" -H "Content-Type: application/json" \
     -d '{"query": "MATCH (n:MilkLot) RETURN count(n) AS lots"}'
   ```

</Steps>

A passcode works **only during your booked slot**. When the 20 minutes end you are signed out, and the demo is restored to its original data, so anything you created is erased. Lost your passcode? Email [connect@graphowl.app](mailto:connect@graphowl.app).

<TabItem label="Run it yourself (early access)">

The early-access container runs on your machine with Docker. It is provided **under the [evaluation licence](/project/licences/)** for 90 days, for evaluation only, not production.

1. **Request access.** Email [connect@graphowl.app](mailto:connect@graphowl.app) with your name, organisation and what you want to evaluate. Include your GitHub username: you are added as a reader of the private package and sent the image tag.
2. **Start it.** See [Run it yourself](/operators/deploy/): log in to the registry, then `docker compose up -d` starts a Postgres database with pgvector and the GraphOWL server.
3. **Check it.** `curl http://localhost:8080/health`, then follow the steps on the demo tab against `http://localhost:8080`.

Until you have a token, use the demo tab: the steps are the same.
