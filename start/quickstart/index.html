Quickstart

Pick how you want to run it.

  • Use the demo
  • Run it yourself (early access)

The demo is a live server loaded with a synthetic dairy cooperative: farms, milk lots, quality tests, production batches and retail sales. Access is by passcode while GraphOWL is in early access.

  1. Get a passcode. Go to demo.graphowl.app and book a 20-minute walkthrough. Straight after booking you are shown a passcode like OWL-XXXX-XXXX, valid for seven days. Copy it then: it is shown once. (No booking link yet? Email connect@graphowl.app and we will send one.)

  2. Open the console. Go to demo.graphowl.app, enter the passcode, and you are in the console with the Northfield Dairy Cooperative workspace.

  3. Ask your first question in the console. Open Query in the left menu, paste this SPARQL and run it. It counts the instances of each class. Imported facts live in named graphs, so the pattern sits inside GRAPH ?g { ... }.

    The answer lists the classes with the most instances: cold-chain readings and quality tests at 46 each, then milk lots at 40, then batch lots at 25. The same screen takes graph patterns (Cypher), such as MATCH (n:MilkLot) RETURN count(n) AS lots.

  4. Or call the API. The passcode is your API key: send it as a bearer token.

    • curl
    • Python
    • TypeScript

  5. Ask it as a graph pattern.

A passcode works for seven days and for a limited number of people at a time; the demo says so if it is full. Lost yours? Email connect@graphowl.app.

Next: From a database to an ontology, the dairy traceability cookbook, or give an agent the same graph.

The early-access container runs on your machine with Docker. It is provided under the evaluation licence for 90 days, for evaluation only, not production.

  1. Request access. Email connect@graphowl.app with your name, organisation and what you want to evaluate. Include your GitHub username: you are added as a reader of the private package and sent the image tag.
  2. Start it. See Run it yourself: log in to the registry, then docker compose up -d starts a Postgres database with pgvector and the GraphOWL server.
  3. Check it. curl http://localhost:8080/health, then follow the steps on the demo tab against http://localhost:8080.

Until you have a token, use the demo tab: the steps are the same.
